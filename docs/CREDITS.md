# Credits and asset provenance

**Little World Kitchen** is an original game created for this repository. Food, equipment, decorative illustrations, generated café imagery, interface design, text, and procedural sound effects were created for this project. No screenshots, character artwork, logos, or extracted assets from Merge Cooking: Theme Restaurant are distributed with it. That game is referenced only as the user's genre and gameplay inspiration.
